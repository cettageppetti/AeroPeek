# Development plan

Version 1.1 implements keyboard navigation, Home/End normalization, type-to-select, Return, and Escape. Dedicated End-key behavior has been confirmed on the target hardware, and the temporary event logging has been removed.

Version 1.2 adds a native material surface, application icons, improved typography and focus treatment, per-workspace window counts, duplicate-app counts, and subdued empty workspaces.

Expandable workspaces and search remain deferred.
