# AeroPeek

A native, keyboard-first macOS workspace overlay for AeroSpace.

Open `AeroPeek.xcodeproj`, select the AeroPeek scheme, and run.

Controls: Up/Down selects, Right expands a workspace, Left collapses it, Home/End jumps, 1–9/A/C/N switches directly, Return activates the selected workspace or window, and Escape closes the overlay.
